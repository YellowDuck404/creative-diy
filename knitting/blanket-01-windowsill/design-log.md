## row composition - option A (green to yellow zones)
single yarn, 8mm needles, garter stitch, stripes run across the 29 cm width  
1 ridge = 2 rows; smallest colour block = 1 ridge, so unused colours can be carried up one side  
inspiration's 2-strand colour mix ("fv. 1 og 2") replaced by alternating single ridges  
start at cast-on edge, read left to right; numbers = ROWS (e.g. "16 G" = knit 16 rows green = 8 ridges)  
G = mørk støvet grøn, Y = lys karry, P = lys pink, S = lys grå

## row composition - option B (green / yellow blend all along)
same rules as option A (single yarn, 8mm, garter, 1 ridge = 2 rows, start at cast-on) — BUT numbers here = RIDGES, not rows (G2 = 2 ridges = 4 rows)  
no zones: green and yellow alternate the whole length (green blocks 1-3 ridges, yellow blocks 1-2 ridges)  
pink / grey sparks alternate, one every 5-9 ridges (uneven on purpose, so they do not form a regular stripe)
