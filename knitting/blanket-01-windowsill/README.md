# Blanket #1: Windowsill

A felted, striped garter-stitch blanket for a windowsill, knitted with a single strand of Fraya Traditional.

<img src="images/colour-preview-option-a.png" alt="Colour preview of the chosen design: green zone, green-to-yellow transition and yellow zone, with pink and grey sparks" width="380">

## At a glance

| | |
|---|---|
| Yarn | Fraya Traditional, 100% wool, 8 mm needles |
| Colours | mørk støvet grøn, lys karry, lys pink, lys grå (8 : 4 : 1 : 1) |
| Cast on | 51 stitches |
| Knit | 264 rows (132 garter ridges) |
| Size on the needles | about 41 × 123 cm |
| Size after felting | 29 × 88 cm |
| Yarn | about 475 g needed, 700 g bought (14 balls) |
