# Creative DIY

Craft and DIY projects by Maria, made by hand with AI as a collaborator.

Each project includes an account of who did what: which tasks were delegated to AI, how the results were checked, and which decisions stayed with Maria. The accounts follow the four principles of AI Fluency: Delegation, Description, Discernment and Diligence.
